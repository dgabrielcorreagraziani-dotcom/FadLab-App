# Revisão com GitHub Copilot

Selecione os agentes em sequência no ambiente Copilot compatível. Em cada etapa, repasse a referência do commit ou PR, critérios de aceitação, resultados dos testes e decisões pendentes.

1. Engenheiro aprova a especificação.
2. Designer detalha os fluxos e componentes.
3. Executor implementa e registra os testes.
4. Questionador verifica regressões e registra achados.
5. Cliente Final percorre os fluxos por perfil.
6. Engenheiro reúne evidências e decide se a mudança volta para correção.

A passagem entre agentes é manual. Os perfis usam o formato [documentado pelo GitHub](https://docs.github.com/en/copilot/reference/custom-agents-configuration).
